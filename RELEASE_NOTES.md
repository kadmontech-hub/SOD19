# SØD Ecosystem V3.1.2 — Floating Portal Refined

## Refinamiento visual aplicado
- Se eliminó visualmente el contenedor rígido detrás del chat.
- El portal fue agrandado y pasó a dominar la escena.
- Los mensajes y la UI ahora renderizan por delante del portal decorativo.
- Se ocultaron elementos intrusivos del Hub mientras la conversación está abierta.
- La animación de entrada ahora refleja la de salida en sentido inverso.
- Se mantuvo el Hub visible detrás del portal para conservar continuidad espacial.
